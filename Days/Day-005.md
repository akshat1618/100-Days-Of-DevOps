
# Day 005 – Install SELinux Packages and Permanently Disable SELinux

## Objective

Install the required SELinux packages on App Server 2 and permanently disable SELinux until further configuration.

## Server Details

- **Server:** App Server 2
- **Hostname:** stapp02
- **User:** steve
- **OS:** CentOS Stream 9

## Tasks Performed

### 1. Install SELinux Packages

Command:

```bash
sudo yum install -y selinux-policy-targeted policycoreutils
```

This installed the required SELinux policy packages and upgraded policycoreutils.

### 2. Permanently Disable SELinux

Open the configuration file:

```bash
sudo vi /etc/selinux/config
```

Find:

```ini
SELINUX=enforcing
```

Change it to:

```ini
SELINUX=disabled
```

Save and exit using `Esc`, then `:wq`.

### 3. Verify SELinux Configuration

Command:

```bash
sudo grep 'SELINUX=' /etc/selinux/config
```

Expected output:

```text
SELINUX=disabled
```

### 4. Verify Installed Packages

Command:

```bash
rpm -q selinux-policy selinux-policy-targeted policycoreutils
```

Verified output:

```text
selinux-policy-38.1.87-1.el9.noarch
selinux-policy-targeted-38.1.87-1.el9.noarch
policycoreutils-3.6-9.el9.x86_64
```

## Important Notes

- SELinux was permanently configured as disabled.
- The server was not rebooted.
- Current runtime SELinux status was intentionally disregarded.
- The configuration will take effect after the scheduled reboot.

## Result

**Successfully completed.**

Required SELinux packages were installed, and SELinux was configured to be permanently disabled through `/etc/selinux/config`.

## Key Learnings

- Installing SELinux policy packages using YUM.
- Understanding `/etc/selinux/config`.
- Configuring persistent SELinux settings.
- Verifying package installation and system configuration.
