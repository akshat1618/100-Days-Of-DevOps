# Day 004 – Script Execute Permissions

## Objective

The xFusionCorp Industries sysadmin team provided a Bash script named `xfusioncorp.sh` for automating backup processes. The script was present on App Server 1, but it did not have the required permissions.

The task was to update `/tmp/xfusioncorp.sh` on **App Server 1 (`stapp01`)** so that every user could read and execute it directly.

## Server Details

- **Server:** App Server 1 (`stapp01`)
- **Login user:** `tony`
- **Script:** `/tmp/xfusioncorp.sh`

## Implementation

### 1. Connect to App Server 1

```bash
ssh tony@stapp01
```

This connects to App Server 1 from the jump host using the `tony` account.

### 2. Set permissions for all users

```bash
sudo chmod 755 /tmp/xfusioncorp.sh
```

This sets the file permissions to `755`:

- **Owner (`7`):** Read, write, and execute.
- **Group (`5`):** Read and execute.
- **Others (`5`):** Read and execute.

Read permission is important for a shell script because the interpreter needs to read its contents. Execute permission allows users to run the script.

### 3. Verify the permissions

```bash
ls -l /tmp/xfusioncorp.sh
```

This displays the file's permissions and ownership. The permission string should begin with:

```text
-rwxr-xr-x
```

You can also check the numeric permissions:

```bash
stat -c '%a %A %n' /tmp/xfusioncorp.sh
```

Expected output:

```text
755 -rwxr-xr-x /tmp/xfusioncorp.sh
```

## What I Learned

This task helped me understand how Linux file permissions control access to scripts. Using `chmod a+x` only adds execute permission, which can leave a script unreadable to other users. Setting permissions to `755` gives the owner full access and allows the group and other users to read and execute the script.

## Important Command

| Command | Purpose |
|---|---|
| `ssh tony@stapp01` | Connect to App Server 1 |
| `sudo chmod 755 /tmp/xfusioncorp.sh` | Give the owner full permissions and all users read and execute permissions |
| `ls -l /tmp/xfusioncorp.sh` | Display file permissions |
| `stat -c '%a %A %n' /tmp/xfusioncorp.sh` | Verify numeric and symbolic permissions |
